# Vision Rule Event Manual Adjustment Flag

Date: 2026-06-20

## Summary

Added `vision_rule_event.manually_adjusted` as a non-null boolean with default
`false` so downstream analytics and review workflows can distinguish generated
rule events from rows corrected or created by a human.

## Behavior

- Generated rule events default to `manually_adjusted=false`.
- `PATCH /accounts/{account_name}/rule-events/{event_id}` marks the updated row
  as `manually_adjusted=true` by default while preserving rule/entity linkage
  and metadata.
- `CreateStateChangeEventRequest.manually_adjusted=true` propagates to any rule
  event generated by the state-change workflow.
- Admin Console bucket event edits now send `manually_adjusted=true` with the
  timing correction payload.
